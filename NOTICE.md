# NOTICE — provenance, attribution, and non-affiliation

This file records where the educational content in this project comes from and
what it is **not**. It exists so the provenance is explicit and readable by
anyone who lands on the repository.

## Source

The skills summaries, worksheet structures, and the handout/worksheet numbers and
printed page numbers used throughout the app refer to:

> Marsha M. Linehan, *DBT Skills Training Handouts and Worksheets, Second
> Edition*. Guilford Press, 2014.

The app paraphrases and summarises that material for educational purposes. It
does **not** reproduce the verbatim text or artwork of the published handouts and
worksheets. Where the app shows a reference such as
`Distress Tolerance Worksheet 6` or `p. 174`, that is a pointer into the printed
book so a reader can find the original.

## For the maintainer (unresolved — needs a human decision)

Software cannot resolve a rights question. The following are decisions only the
repository owner can make, and they are **not** settled by this file:

1. **Confirm your basis for publishing.** If this is used only within your own
   therapy group, that is a very different risk posture from a public website and
   a public repository. Decide which one you actually want.
2. **If it must stay public, consider** (a) keeping it non-indexed by search
   engines, (b) removing any content that mirrors the book's structure more
   closely than a pointer, and (c) obtaining written permission from the rights
   holder before wider distribution.
3. **Add an explicit license** if you want others to reuse the *code*. The
   repository currently has no clear license (GitHub reports "NOASSERTION"),
   which means others have no permission to reuse it even though it is public.
   Note that a code license cannot license the underlying therapy material.
4. **Keep the removal path open.** The in-app `/about` page links to the issue
   tracker for takedown requests. Respond to those promptly.

## Removal requests

If you hold rights in any material referenced here and believe it is being used
inappropriately, open an issue at
<https://github.com/sunnyskyess420/dbt-skills-reference/issues> and it will be
reviewed and corrected or removed promptly.
